# Бюро путешествий (Travel World)

Веб-приложение туристического агентства на Django. Курсовой проект
по дисциплине «Технология разработки программного обеспечения»,
траектория А — full-stack Django.

Посетитель смотрит каталог туров по направлениям, читает описания
и отзывы. Зарегистрированный пользователь публикует свои туры,
оставляет отзывы и собирает избранное. Администратор управляет
содержимым через админ-панель Django.

## Возможности

**Без регистрации**

- каталог туров с постраничным выводом по 6 записей
- отбор по направлениям
- страница тура: описание, цена, длительность, фото, отзывы
- поиск по названию и описанию с подсказками по мере ввода
- счётчик просмотров

**После входа**

- создание, редактирование и удаление своих туров
- загрузка фотографии тура
- черновики: тур без признака «Опубликован» виден только автору
- отзывы без перезагрузки страницы
- избранное
- профиль с аватаром и личными данными

**Администратор**

- админ-панель: туры, направления, отзывы, пользователи
- скрытие отзыва без удаления записи
- выдача прав и блокировка учётных записей

## Установка

```bash
git clone https://github.com/Seihposwag/sofa-travel-app.git
cd sofa-travel-app
py -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
```

Создать базу и наполнить её тестовыми данными:

```bash
cd backend
..\.venv\Scripts\python manage.py migrate
..\.venv\Scripts\python manage.py seed_demo
```

## Запуск

```bash
cd backend
..\.venv\Scripts\python manage.py runserver
```

Сайт — http://localhost:8000, админ-панель — http://localhost:8000/admin/

Тестовые аккаунты, пароль у всех `travel2026`:

| Логин | Роль |
|---|---|
| `admin` | администратор |
| `manager` | пользователь, автор туров |
| `traveller` | пользователь, автор отзывов |

## Тесты

```bash
cd backend
..\.venv\Scripts\python manage.py test
```

21 тест: модели и связи, каталог, пагинация, поиск, отбор по
направлению, счётчик просмотров, разграничение доступа к правке
и удалению, AJAX-обработчики, регистрация, вход, выход, профиль.
