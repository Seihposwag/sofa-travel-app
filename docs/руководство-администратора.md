# Руководство администратора

Веб-приложение «Бюро путешествий» (Travel World)

---

## 1. Требования к окружению

| Компонент | Версия |
|---|---|
| Python | 3.12 и новее |
| Django | 6.1 |
| Pillow | 12.3 |
| python-dotenv | 1.2 |
| База данных | SQLite, входит в состав Python |

Отдельный сервер базы данных ставить не нужно.

## 2. Установка

Скачать проект и перейти в его каталог:

```bash
git clone https://github.com/Seihposwag/sofa-travel-app.git
cd sofa-travel-app
```

Создать виртуальное окружение и установить зависимости:

```bash
py -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
```

На Linux и macOS вместо `.venv\Scripts\` используется `.venv/bin/`.

## 3. Настройка

Скопировать файл с примером переменных окружения:

```bash
copy .env.example .env
```

Содержимое `.env`:

| Переменная | Назначение |
|---|---|
| `SECRET_KEY` | Ключ подписи сессий и токенов. Для реальной работы заменить на случайную строку |
| `DEBUG` | Режим отладки. `True` для разработки |
| `ALLOWED_HOSTS` | Адреса, с которых принимаются запросы |

Файл `.env` в репозиторий не попадает, он указан в `.gitignore`.
Если файла нет, Django берёт значения по умолчанию из `settings.py`.

## 4. Создание базы данных

```bash
cd backend
..\.venv\Scripts\python manage.py migrate
```

Команда создаёт файл `backend/db.sqlite3` и все таблицы.

Наполнить базу тестовыми данными:

```bash
..\.venv\Scripts\python manage.py seed_demo
```

Команда добавляет 6 направлений, 8 туров, 16 отзывов и три аккаунта
с паролем `travel2026`: `admin`, `manager`, `traveller`.
Повторный запуск ничего не дублирует.

Создать своего администратора вручную:

```bash
..\.venv\Scripts\python manage.py createsuperuser
```

## 5. Запуск

```bash
cd backend
..\.venv\Scripts\python manage.py runserver
```

Сайт открывается по адресу http://localhost:8000,
админ-панель — http://localhost:8000/admin/

Остановка сервера — Ctrl+C.

Запуск на другом порту:

```bash
..\.venv\Scripts\python manage.py runserver 8080
```

## 6. Админ-панель

Вход по адресу `/admin/` под учётной записью с признаком
«Статус персонала». Разделы:

| Раздел | Что в нём |
|---|---|
| Направления | Список стран. Удалить направление, у которого есть туры, нельзя |
| Туры | Все туры. Фильтр по публикации и направлению, поиск по названию и описанию. Цену и признак публикации можно менять прямо в списке |
| Отзывы | Все отзывы. Признак «Показывать» скрывает отзыв с сайта, не удаляя запись |
| Избранное | Пары пользователь–тур |
| Пользователи | Учётные записи, права, профили |

### Как скрыть спам в отзывах

Раздел «Отзывы», найти запись, снять галочку «Показывать», сохранить.
Отзыв исчезнет со страницы тура, но останется в базе.

### Как выдать права администратора

Раздел «Пользователи», открыть учётную запись, включить «Статус персонала».
Для полного доступа включить также «Статус суперпользователя».

### Как заблокировать пользователя

Раздел «Пользователи», снять галочку «Активный». Учётная запись
сохранится, но войти под ней будет нельзя.

## 7. Структура проекта

```
sofa-travel-app/
├── backend/
│   ├── manage.py             запуск команд Django
│   ├── requirements.txt      список зависимостей
│   ├── db.sqlite3            база данных
│   ├── config/               настройки и корневые адреса
│   ├── tours/                предметная область
│   └── users/                пользователи и доступ
├── templates/                HTML-шаблоны
├── static/                   стили, скрипты, изображения
├── media/                    загруженные фото и аватары
├── docs/                     документация и диаграммы
└── README.md
```

## 8. Обслуживание

### Резервная копия

Достаточно скопировать два объекта:

```bash
copy backend\db.sqlite3 backup\db.sqlite3
xcopy media backup\media /E /I
```

### Восстановление

Вернуть файл `db.sqlite3` и каталог `media` на место.
Если база утеряна полностью, пересоздать её командами
`migrate` и `seed_demo` — но пользовательские данные при этом
не восстановятся.

### Просмотр таблиц

```bash
cd backend
..\.venv\Scripts\python manage.py dbshell
```

## 9. Запуск тестов

```bash
cd backend
..\.venv\Scripts\python manage.py test
```

Тесты работают на отдельной временной базе, рабочие данные
не затрагиваются. Всего 21 тест: модели, каталог, пагинация, поиск,
разграничение доступа, AJAX-обработчики, регистрация и вход.

## 10. Частые неполадки

| Проблема | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: No module named 'django'` | Не активировано окружение | Запускать через `..\.venv\Scripts\python` |
| `That port is already in use` | Порт 8000 занят | Запустить на другом порту или закрыть предыдущий сервер |
| Каталог пустой | База не наполнена | Выполнить `manage.py seed_demo` |
| `no such table` | Миграции не применены | Выполнить `manage.py migrate` |
| Фото не показываются | Нет каталога `media` или `DEBUG = False` | Создать каталог, проверить режим отладки |
| Страница без оформления | Не загрузился Bootstrap с CDN | Проверить подключение к интернету |
