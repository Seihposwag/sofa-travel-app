# Руководство пользователя

Веб-приложение «Бюро путешествий» (Travel World)

---

## 1. Что это за сайт

Сайт туристического агентства. Здесь можно посмотреть туры по разным
направлениям, прочитать описания и отзывы. Если зарегистрироваться,
появляется возможность добавлять свои туры, писать отзывы и сохранять
интересные предложения в избранное.

Адрес сайта после запуска: **http://localhost:8000**

## 2. Что доступно без регистрации

| Возможность | Где |
|---|---|
| Каталог всех туров | Главная страница |
| Туры одного направления | Меню «Направления» или список слева на главной |
| Полное описание тура | Нажать на название тура в каталоге |
| Поиск | Поле «Поиск тура» в верхней панели |
| Отзывы о туре | Внизу страницы тура |

## 3. Каталог

На главной странице выводится шесть туров. Внизу кнопки «Назад»
и «Вперёд» и номера страниц — по ним листается каталог.

Слева список направлений. В скобках у каждого — сколько туров
в этом направлении. Нажатие на название показывает только его туры.

На карточке тура видно направление, короткое описание, цену,
длительность, число отзывов и просмотров.

## 4. Поиск

Поле поиска находится в верхней панели.

1. Начните вводить название тура или страну.
2. После второго символа под полем появятся подсказки.
3. Нажмите на подсказку — откроется страница тура.
4. Либо нажмите Enter — откроется список всех подходящих туров.

Поиск смотрит и название, и описание тура. Например, по слову
«вулканы» найдётся тур на Бали, потому что слово есть в описании.

## 5. Регистрация

1. Нажмите «Регистрация» в верхней панели.
2. Придумайте имя пользователя — латинские буквы, цифры, знаки `@ . + - _`.
3. Укажите адрес электронной почты. Одна почта — один аккаунт.
4. Введите пароль дважды.

Требования к паролю: не короче 8 символов, не только цифры,
не слишком простой и не похожий на имя пользователя.

После регистрации вход выполняется автоматически.

## 6. Вход и выход

Вход — кнопка «Вход» в верхней панели, затем имя пользователя и пароль.
Если данные неверные, появится сообщение «Неверный логин или пароль».

Выход — кнопка «Выйти» справа в верхней панели.

Тестовые аккаунты, пароль у всех `travel2026`:

| Логин | Кто |
|---|---|
| `admin` | администратор, есть доступ к админ-панели |
| `manager` | обычный пользователь, автор туров |
| `traveller` | обычный пользователь, автор отзывов |

## 7. Как добавить свой тур

1. Войдите в систему.
2. Нажмите «Добавить тур» в верхней панели.
3. Заполните поля:

| Поле | Что вводить |
|---|---|
| Название | Название тура |
| Направление | Выбрать страну из списка |
| Описание | Подробный текст: что входит, маршрут, условия |
| Цена, руб. | Число больше нуля |
| Дней | Длительность тура |
| Фото | Файл с изображением, можно не заполнять |
| Опубликован | Галочка — тур виден всем. Без галочки — черновик, видите только вы |

4. Нажмите «Добавить».

Если цена указана нулевая или отрицательная, форма вернётся
с сообщением «Цена должна быть больше нуля».

## 8. Свои туры

Раздел «Мои туры» в верхней панели — таблица всех ваших туров.
Видно направление, цену, статус (опубликован или черновик)
и число отзывов. Справа кнопки «Изменить» и «Удалить».

Удаление спрашивает подтверждение. Вместе с туром удаляются
все его отзывы, вернуть их нельзя.

Изменять и удалять можно только свои туры. При попытке открыть
чужой появится сообщение «Можно менять только свои туры».

## 9. Отзывы

Форма отзыва находится внизу страницы тура и доступна только
после входа.

1. Напишите текст, не короче 10 символов.
2. Нажмите «Отправить отзыв».

Отзыв появится сразу над остальными, страница не перезагрузится.
Счётчик рядом со словом «Отзывы» увеличится.

Если текст слишком короткий, под полем появится сообщение
«Отзыв слишком короткий».

## 10. Избранное

На странице тура есть кнопка «В избранное». Нажатие сохраняет тур
в личный список, надпись меняется на «В избранном». Повторное
нажатие убирает тур из списка. Страница при этом не перезагружается.

Сохранённые туры собраны в разделе «Избранное» в верхней панели.

## 11. Профиль

Нажмите на своё имя в верхней панели.

Слева аватар, роль и счётчики: сколько туров опубликовано,
сколько в избранном, сколько отзывов оставлено. Справа форма
личных данных: имя, фамилия, почта, телефон, «О себе», аватар.

После правки нажмите «Сохранить».

## 12. Возможные сообщения

| Сообщение | Что значит | Что делать |
|---|---|---|
| Неверный логин или пароль | Данные не совпали с базой | Проверить раскладку и регистр букв |
| Такая почта уже зарегистрирована | Почта занята другим аккаунтом | Указать другую почту |
| Цена должна быть больше нуля | В поле цены ноль или отрицательное число | Ввести положительное число |
| Отзыв слишком короткий | Текст меньше 10 символов | Дописать текст |
| Можно менять только свои туры | Открыт чужой тур на правку | Вернуться в «Мои туры» |
| Этот тур снят с публикации | Тур в черновиках у другого автора | Выбрать другой тур из каталога |
| Обязательное поле | Поле формы не заполнено | Заполнить поле |
