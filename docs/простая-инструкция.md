# Travel World: совсем простая инструкция

## Что это

Это маленький сайт с турами. Здесь можно смотреть поездки, искать их,
читать отзывы и, после входа, добавлять свои туры и отзывы.

## Как запустить

Откройте PowerShell в папке проекта. При первом запуске создайте
для сайта отдельную папку с Python и установите нужные части:

```powershell
py -m venv .venv
.\.venv\Scripts\pip install -r backend\requirements.txt
```

Затем подготовьте сайт и включите его:

```powershell
cd backend
..\.venv\Scripts\python manage.py migrate
..\.venv\Scripts\python manage.py seed_demo
..\.venv\Scripts\python manage.py runserver
```

Откройте в браузере: http://localhost:8000

Первая команда создаёт для сайта отдельное место с Python. Вторая
скачивает Django и другие нужные детали. `migrate` создаёт файл базы,
`seed_demo` кладёт туда готовые примеры, а `runserver` включает сайт.
В следующие разы достаточно перейти в `backend` и выполнить только
последнюю команду.

Чтобы остановить сайт, вернитесь в окно PowerShell и нажмите `Ctrl + C`.

## Как пользоваться

- **Каталог** — главная страница со всеми турами. Страны слева работают как фильтр, строка сверху ищет по словам.
- **Тур** — отдельная поездка: описание, цена, дни, фото и отзывы.
- **Вход** — даёт возможность написать отзыв и добавить свой тур.
- **Админка** — служебная страница, где можно управлять турами, странами, отзывами и пользователями: http://localhost:8000/admin/

Самый простой путь: откройте каталог, выберите страну или найдите
слово, откройте понравившийся тур и прочитайте отзывы. После входа
появится кнопка добавления тура, а на странице тура — поле для отзыва.
Свой тур можно изменить или удалить; чужие туры менять нельзя.

Для знакомства уже есть пользователи. Пароль у всех: `travel2026`.

| Логин | Кто это |
|---|---|
| `admin` | администратор |
| `manager` | добавляет туры |
| `traveller` | пишет отзывы |

## Как это работает внутри

1. Браузер просит страницу, например каталог.
2. Django берёт нужные данные из маленькой базы `db.sqlite3`.
3. Он собирает страницу по шаблону и отправляет её браузеру.
4. Когда пользователь пишет отзыв, JavaScript отправляет его незаметно, поэтому страница не перезагружается.

У сайта есть две главные части: `tours` отвечает за страны, туры и
отзывы, а `users` — за регистрацию, вход и профиль. Оформление страниц
лежит в `templates`, картинки и стили — в `static`, а загруженные фото
туров — в `media`.

**Django** — веб-фреймворк на Python: он принимает запросы браузера,
работает с базой данных и формирует страницы сайта.
**База данных** — файл, где сайт хранит туры, пользователей и отзывы.
**Шаблон** — заготовка внешнего вида страницы.
**Администратор** — пользователь с правом менять всё на сайте.
**Отзыв без перезагрузки** — сообщение отправляется в фоне и сразу
появляется на странице.
**Маршрут (URL)** — правило, которое говорит сайту, что открыть по
определённому адресу. Например, `/admin/` открывает админ-панель.
**Модель** — описание того, какие данные хранить. В проекте есть модели
«Страна», «Тур», «Отзыв» и «Пользователь».
**Форма** — поля на странице для ввода данных. Перед сохранением Django
проверяет, что они заполнены правильно.
**Миграция** — инструкция для Django, как создать или изменить таблицы
базы данных. Команда `migrate` применяет эти инструкции.
**JavaScript** — язык в браузере. Здесь он позволяет отправлять отзыв
без обновления всей страницы.

## Для защиты курсовой

Коротко о проекте можно сказать так: «Travel World — веб-приложение
туристического агентства на Python и Django. Гость смотрит и ищет туры,
пользователь после входа добавляет туры и отзывы, а администратор
управляет данными через встроенную админ-панель».

- **Технологии:** Python 3.14, Django 6.1, Django Templates, Bootstrap 5,
  JavaScript и SQLite.
- **База данных:** SQLite хранится в одном файле `backend/db.sqlite3`.
  Она не требует отдельного сервера и удобна для учебного проекта.
- **Данные:** есть четыре главные сущности: страна, тур, отзыв и
  пользователь. У тура одна страна и один автор; у тура может быть много
  отзывов.
- **Работа с базой:** Django ORM переводит действия с моделями в SQL-запросы,
  поэтому в коде не нужно писать SQL вручную.
- **Страницы:** путь обработки выглядит так: `URL → view → model → template
  → HTML`. Адрес выбирает функцию, функция получает данные, а шаблон
  собирает готовую страницу для браузера.
- **Безопасность:** пароль хранится не открытым текстом, а в виде хеша.
  Формы проверяются на сервере и защищены CSRF-токеном. Действия с турами
  доступны только после входа; менять и удалять чужой тур нельзя.
- **Динамика:** отзыв отправляется через `fetch` без перезагрузки страницы.
  Сервер возвращает JSON, а JavaScript сразу добавляет новый отзыв в список.
- **Управление:** администратор работает через `/admin/`; Django сам создаёт
  этот раздел по описанию моделей.

На вопрос «почему Django?» можно ответить: он уже даёт готовые и надёжные
механизмы для пользователей, форм, доступа, защиты, базы данных и
админ-панели. На вопрос «почему SQLite?» — это простая файловая база без
отдельной настройки сервера, которой достаточно для небольшого учебного
сайта.
