# Техническое задание

Проект: веб-приложение «Бюро путешествий» (Travel World)
Дисциплина: Технология разработки программного обеспечения
Траектория: А — full-stack Django

---

## 1. Назначение и цель

Веб-приложение туристического агентства. Посетитель смотрит каталог
туров по направлениям, читает описания и отзывы. Зарегистрированный
пользователь публикует свои туры и оставляет отзывы. Администратор
управляет содержимым сайта.

Цель — разработать веб-приложение на Django с серверным рендерингом
шаблонов, сессионной аутентификацией и AJAX-запросом для отправки
отзыва без перезагрузки страницы.

## 2. Роли пользователей

| Роль | Кто это | Что может |
|---|---|---|
| Гость | Не авторизован | Смотреть каталог и описания туров, искать, отбирать по направлению |
| Пользователь | Авторизован | Всё, что гость, плюс публикация и правка своих туров, отзывы, профиль |
| Администратор | `is_staff = True` | Всё, что пользователь, плюс админ-панель: любые туры, направления, отзывы, пользователи |

## 3. Функциональные требования

### Публичная часть

| Код | Требование |
|---|---|
| ФТ-1 | Каталог туров с постраничным выводом по 6 записей |
| ФТ-2 | Отбор туров по направлению |
| ФТ-3 | Страница тура: описание, цена, длительность, фото, автор, отзывы |
| ФТ-4 | Поиск по названию и описанию тура |
| ФТ-5 | Регистрация нового пользователя |
| ФТ-6 | Вход и выход |

### Закрытая часть

| Код | Требование |
|---|---|
| ФТ-7 | Создание тура с загрузкой фотографии |
| ФТ-8 | Редактирование своего тура |
| ФТ-9 | Удаление своего тура с подтверждением |
| ФТ-10 | Добавление отзыва без перезагрузки страницы |
| ФТ-11 | Просмотр и правка профиля |

### Административная часть

| Код | Требование |
|---|---|
| ФТ-12 | Управление турами: создание, правка, удаление |
| ФТ-13 | Управление направлениями |
| ФТ-14 | Управление отзывами |
| ФТ-15 | Управление пользователями и их правами |

## 4. Нефункциональные требования

| Категория | Требование |
|---|---|
| Совместимость | Chrome 90+, Firefox 88+, Safari 14+ |
| Интерфейс | Адаптивная вёрстка, работа на экране от 360 пикселей |
| Безопасность | Пароли хранятся в виде хеша, формы защищены csrf-токеном, данные экранируются шаблонизатором |
| Разграничение доступа | Закрытые страницы недоступны без сессии, чужой тур нельзя изменить |
| Целостность данных | Внешние ключи, уникальность логина и почты, проверка цены |
| Производительность | Связанные объекты подгружаются через `select_related`, по частым полям заданы индексы |
| Поддерживаемость | База данных приведена к третьей нормальной форме |

## 5. Ограничения

- Оплата и бронирование туров не реализуются, приложение остаётся витриной.
- Подтверждение адреса почты при регистрации не выполняется.
- Приложение работает на сервере разработки Django, промышленное развёртывание за рамками задания.
- База данных — SQLite, один файл.

## 7. Модели данных

| Модель | Назначение | Ключевые поля |
|---|---|---|
| `User` | Пользователь, наследник `AbstractUser` | `username`, `email`, `bio`, `phone` |
| `Country` | Направление, категория для туров | `title`, `description` |
| `Tour` | Туристическое предложение | `title`, `description`, `price`, `duration_days`, `photo` |
| `Review` | Отзыв о туре | `text`, `created_at` |

## 8. Структура адресов

| Адрес | Назначение | Доступ |
|---|---|---|
| `/` | Каталог туров, поиск | Все |
| `/country/<id>/` | Туры направления | Все |
| `/tour/<id>/` | Страница тура | Все |
| `/tour/new/` | Создание тура | Пользователь |
| `/tour/<id>/edit/` | Правка тура | Автор, администратор |
| `/tour/<id>/delete/` | Удаление тура | Автор, администратор |
| `/users/register/` | Регистрация | Гость |
| `/users/login/` | Вход | Гость |
| `/users/logout/` | Выход | Пользователь |
| `/users/profile/` | Профиль | Пользователь |
| `/ajax/review/<id>/` | Добавление отзыва, JSON | Пользователь |
| `/admin/` | Админ-панель | Администратор |

## 9. Критерии приёмки

1. Все функциональные требования из раздела 3 работают.
2. Каталог разбит на страницы, поиск находит туры по названию и описанию.
3. Регистрация, вход и выход работают, пароль в базе хранится хешем.
4. Чужой тур изменить или удалить нельзя.
5. Отзыв добавляется без перезагрузки страницы.
6. Админ-панель открывается только пользователю с `is_staff`.
7. Автоматические тесты проходят без ошибок.
8. Интерфейс не ломается на ширине экрана 360 пикселей.
